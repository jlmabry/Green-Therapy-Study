# Green Therapy Mood Study

## Overview
A research project analyzing the impact of nature exposure on mood and stress levels. Includes data collection materials, R scripts, and statistical analysis.

## Features
- Survey-based data collection
- R scripts for cleaning and analysis
- Visualizations of mood changes
- Statistical testing

## Technologies Used
- R
- ggplot2
- dplyr
- Statistical Analysis

## How It Works
Participants completed mood surveys before and after exposure to nature. Data was analyzed using R to identify statistically significant changes.
